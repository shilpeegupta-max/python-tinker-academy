# 🚀 Python Tinker Academy (15-Day Interactive Curriculum)

An interactive, gamified 15-Day Python learning web application engineered for young coders and beginners. Features embedded client-side Python execution (via Skulpt), split-screen workspace modals, step-by-step curriculum walkthroughs, AI mentor guide drawers, and a graduation diploma generator.

---

## 🌟 Key Features

- **⚡ In-App Split-Screen Workspace Modal**:
  - Click any day card on the main roadmap to open a floating dual-pane learning environment without navigating away.
  - **Left Pane**: Step-by-step concept walkthroughs, real-world analogies, syntax cheat sheets, line-by-line blueprints, and tinker missions.
  - **Right Pane**: Embedded Python code editor & live terminal runtime.

- **🐍 Embedded Skulpt Python Engine**:
  - Runs Python code (including `turtle` graphics and `time.sleep`) directly inside the browser using Web WebSockets/Canvas — zero backend or setup required!

- **🧠 Methodology Guide Popups**:
  - Click any methodology widget (**10 Min: Concept**, **15 Min: Live-Code**, or **20 Min: Tinker & Break**) on the top header banner to open detailed step-by-step student practice guides.

- **🤖 AI Mentor Guide Drawer**:
  - Slide-out mentor drawer offering structured hints, debug checklists, and logic explanations.

- **🎓 Graduation Diploma Generator**:
  - Dynamic completion progress tracker and printable graduation certificate with editable student name field.

## 📅 15-Day Curriculum Map

1. **Day 1**: The Megaphone (`print()`, Strings, Escape Sequences)
2. **Day 2**: Labeled Snack Boxes (Variables, Data Types, `type()`)
3. **Day 3**: Input Magic Wand (`input()`, Type Casting, F-Strings)
4. **Day 4**: The Security Guard (If/Else, Comparison Operators)
5. **Day 5**: The Bouncer Gate (Logical Operators, Nested Conditions)
6. **Day 6**: The Repeat Robot (For Loops, `range()`, Iteration)
7. **Day 7**: The Loop Vault (While Loops, Infinite Loops, Breaks)
8. **Day 8**: The Inventory Chest (Lists, Indexing, Slicing, Methods)
9. **Day 9**: The Magic Spellbook (Dictionaries, Key-Value Pairs)
10. **Day 10**: The Custom Tool Factory (`def`, Functions, Return Values)
11. **Day 11**: The Scope Shield (Local vs Global Variables)
12. **Day 12**: The Canvas Painter (Turtle Graphics, Coordinate Geometry)
13. **Day 13**: The Turtle Architect (Turtle Loops, Shapes, Colors)
14. **Day 14**: The Bug Exterminator (Try/Except, Debugging Strategies)
15. **Day 15**: Capstone Game Engineering (Building a Full Interactive Game)

## 💻 Local Development

To run locally using Python's built-in HTTP server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/index.html` in your browser.
