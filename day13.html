Polishing Games & Defensive Coding

💡 Everyday Analogy:
A polished game never crashes when a user types nonsense. It validates inputs, uses bright colors, and hides fun easter eggs!

Syntax Cheat Sheet:

# ANSI Terminal Colors
RED = "\\033[91m"
GREEN = "\\033[92m"
CYAN = "\\033[96m"
RESET = "\\033[0m"

print(RED + "⚠️ WARNING: Low Health!" + RESET)
print(GREEN + "💚 Health Restored!" + RESET)

# Defensive Input Loop
while True:
    choice = input("Pick 1 or 2: ")
    if choice in ["1", "2"]:
        break
    print("❌ Invalid entry! Please type 1 or 2.")
