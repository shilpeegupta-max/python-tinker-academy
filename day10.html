💡 Everyday Analogy:

Syntax Cheat Sheet:

# Creating a dictionary
player_stats = {
    "name": "Shadow Ninja",
    "level": 15,
    "health": 250,
    "has_keycard": True
}

# Looking up a value
print("Player Name:", player_stats["name"])

# Updating a value
player_stats["health"] = 300

# Adding a new key
player_stats["weapon"] = "Katana"

Key Takeaways:
